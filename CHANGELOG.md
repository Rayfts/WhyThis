# Changelog

This file records notable user-facing changes to WhyThis. The project is currently pre-1.0, so CLI and evidence-format details may evolve while the deterministic archaeology model stabilizes.

## Unreleased

No tagged public release has been declared yet. Future features, fixes, evidence-model changes, compatibility changes, and security-relevant behavior changes should be summarized here before release.

## Initial public foundation

The current foundation includes deterministic Git archaeology, incremental SQLite indexing, GitHub enrichment, explainable historical-risk analysis, a local API/TUI, FACT / INFERENCE / UNKNOWN separation, and the initial coding-agent adapter set. Earlier development history is preserved in Git.
